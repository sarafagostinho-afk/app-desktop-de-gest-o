# Aplicação Desktop de Gestão - Gestor de Inventário Desktop
Desenvolvimento de uma aplicação desktop nativa para gestão de inventário e stock. Implementação de operações CRUD completas (registo, listagem dinâmica em tabela com Treeview, eliminação e edição via janelas modais), validação rigorosa de formulários e integração com base de dados relacional SQLite para persistência de dados.
